# Security Policy

## Reporting a vulnerability

Please do not disclose security vulnerabilities in public GitHub issues.

Report them privately through the
[LensUp contact page](https://lensup.ai/contact/). Include:

- the affected endpoint or behavior;
- clear reproduction steps;
- the potential impact;
- and any safe supporting evidence.

Do not include real identity documents, private photographs, API keys, or other
sensitive user data in a report.

## Scope

This repository contains public metadata and documentation. The production MCP
implementation is hosted separately at `https://mcp.lensup.ai/mcp`.
